# 🤖 GenAI-ChatBot (RAG Chatbot)

GenAI-ChatBot is a **Retrieval-Augmented Generation (RAG)** conversational AI application. It allows users to chat and ask questions based on custom PDF documents. The application retrieves relevant contexts from a vector database and uses OpenAI's GPT-4o to generate accurate, context-aware responses.

🌐 **Live Demo**: [https://genai-chatbot-zjel.onrender.com](https://genai-chatbot-zjel.onrender.com)

---

## 🌟 Features
- **Document QA (RAG)**: Ask questions directly related to PDF documents uploaded in the `data/` folder.
- **Hybrid Embedding Model**: Uses `sentence-transformers/all-MiniLM-L6-v2` via Hugging Face Serverless Inference API (uses <50MB RAM, making it perfect for free tiers like Render).
- **Vector Database**: Semantic search powered by **Pinecone Vector Database**.
- **Advanced LLM**: Conversational responses generated by OpenAI's **GPT-4o**.
- **Interactive UI**: A clean, responsive, and modern web chat interface.

---

## 🛠️ Tech Stack
- **Backend**: Python, Flask
- **Orchestration**: LangChain, LangChain-Community
- **Vector Store**: Pinecone
- **Embeddings**: Hugging Face Hub (Serverless Inference API)
- **LLM**: OpenAI (GPT-4o)
- **Production Server**: Gunicorn

## 🚀 How to Run the Project Locally

### 1. Clone the repository
```bash
git clone https://github.com/Abhijeet1102/GenAI-ChatBot.git
cd GenAI-ChatBot
```

### 2. Create and Activate a Virtual Environment
```bash
# Create virtual environment
python -m venv venv

# Activate on Windows:
venv\Scripts\activate

# Activate on macOS / Linux:
source venv/bin/activate
```

### 3. Install Dependencies
```bash
pip install -r requirements.txt
```

### 4. Configure Environment Variables
Create a `.env` file in the root directory and add your API keys:
```env
PINECONE_API_KEY=your_pinecone_api_key_here
OPENAI_API_KEY=your_openai_api_key_here
HUGGINGFACEHUB_API_TOKEN=your_huggingface_api_token_here
```

### 5. Index the PDF Documents
Place your PDF files inside the `data/` directory, then run the indexing script to split the text, generate embeddings, and upload them to Pinecone:
```bash
python store_index.py
```

### 6. Start the Web App
Run the Flask application locally:
```bash
python app.py
```
Open your browser and navigate to `http://127.0.0.1:5000`.

## ☁️ Deployment on Render

This project is optimized to run on **Render's Free Tier** (512MB RAM limit).

- **Start Command**: `gunicorn app:app`
- **Config**: Gunicorn is configured via [gunicorn.conf.py](file:///c:/Users/ABHI/Downloads/GenAI-ChatBot/gunicorn.conf.py) to bind to `0.0.0.0:$PORT` and has an increased timeout of `120s` to prevent worker timeouts.
- **Required Environment Variables in Render**:
  - `PINECONE_API_KEY`
  - `OPENAI_API_KEY`
  - `HUGGINGFACEHUB_API_TOKEN`
