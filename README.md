# GenAI-ChatBot

GenAI-ChatBot is a Python-based conversational AI project designed to interact with users in a natural and intelligent way.

## 🌟 Features
- Supports both **English and Hindi** languages
- Conversational AI with prompt-based responses
- Simple and modular Python project structure
- Easy to extend for more languages and features

## 🛠️ Tech Stack
- Python
- Generative AI / LLM APIs
- Jupyter Notebook (for experiments)
- Flask / FastAPI (if applicable)

## 🚀 How to Run the Project
1. Clone the repository
     ```bash
   git clone https://github.com/USERNAME/GenAI-ChatBot.git
   cd GenAI-ChatBot

2. Create a virtual environment (optional but recommended):
        ```bash
        python -m venv venv
        
    # Activate the virtual environment:
        On Windows:

        ```bash
         venv\Scripts\activate
         
        On macOS / Linux:

        ```bash
        source venv/bin/activate

3. Install dependencies:

    ```bash
    pip install -r requirements.txt

4. Configure environment variables:
    ---> Create a .env file in the project root directory

    ---> Add required API keys or configuration values:

    ```env
    API_KEY=your_api_key_here

5. Run the application:

    ```bash
    python app.py

6. Start using the chatbot:
    ---> Interact with the chatbot using English or Hindi

    ---> Follow the on-screen or terminal instructions as applicable
